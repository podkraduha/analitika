# Задание 2 - API-пайплайн: данные - LLM - результат
Цель: написать рабочий скрипт, который автоматически отправляет данные в LLM через API и получает структурированный ответ.

### Ход работы: 
1. Написан скрипт на языке Python, который выполняет пайплайн
2. Он читает входные данные из csv-файла "news_input.csv"
3. Формирует запрос и отправляет его в LLM (Qwen 3) через API, полученный в GroqCloud
4. Получает от LLM структурированный ответ в формате json
5. Сохраняет результат в файл "output_summaries.json"

Задача: саммаризация: скрипт читает новости - LLM генерирует краткое содержание каждой - результат в json

### Инструкция запуска:
1. Клонирровать репозиторий
2. Установить все необходимые пакеты: вручную или через терминал `pip install groq pandas` или `pip install -r requirements.txt`
3. Вставить API-ключ в необходимое место на 5 строке
4. Запустить main.py через кнопку "run" или через терминал `python main.py`

# Немного от себя
1. Изначально я пыталась получить апи-ключ через сайт OpenRouter, но там так и не получилось достучаться до какой-либо модели, поэтому использовала Грок, получила там Апи-ключ, проверила его работу на ллм Ллама, а затем переделала на Квен. В сравнении среди этих двух ллм для этой задачи лучше справился Квен, он лучше отчитывает новости, и старается вместить в ответ всю новость по максимуму, Ллама же часто просто заголовок просто переписывала.
2. По-моему мнению, Квен достаточно хорошо справился с поставленной задачей, достаточно быстро отчитывал все новости (1 сек без размышления, 3 сек с размышлениями), и выдавал в целом правильный ответ, в соответствии с промтом (я меняла условия, насколко краткое содержание мне нужно). В целом, можно использовать его для этой функции, но данные в инпут файле нужно приводить в нужный вид.
3. Лимиты на квен через грок хорошие: 60 в минуту, 1к в день, 6к токенов в минуту, 500к токенов в день. Для бесплатной хорошо думающей модели это достаточно для не супер сложных задач.
